# Mastering n8n — A Chapter-by-Chapter Guide

This is a self-paced curriculum broken into chapters, one file per topic. Go through them in order — each one builds on the last.

## Your specific situation

You currently have **two separate n8n setups**:
1. An **n8n.cloud** account (14-day trial, browser-based)
2. A **local self-hosted** instance (installed via npm, license key activated)

These do not sync. Nothing moves between them automatically. Since the cloud trial expires and the local instance doesn't, **do your primary learning and workflow-building on the local instance**. Use the cloud trial only to peek at Pro-tier features (Insights dashboard, workflow history) before it expires — export anything you want to keep first.

## How to use this

Don't just read — after each chapter, open your local n8n instance and actually do the thing described. n8n is a hands-on tool; the concepts click much faster once you've dragged a node around yourself.
